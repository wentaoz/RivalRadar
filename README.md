# RivalRadar

## 中文简介

RivalRadar 是一款 macOS 竞品情报监控工具，支持 RSS、网页、Tavily 搜索和 Chrome 会话来源采集，结合 AI 去重、摘要、趋势判断和报告生成，帮助持续追踪竞品动态与市场信号。

## English Overview

RivalRadar is a macOS competitive-intelligence monitor for RSS, web pages, Tavily search, and Chrome session sources. It combines AI-assisted deduplication, summaries, trend judgment, and report generation to track competitor and market signals.
